# NESCO Elevators — Free Static Deployment

This package is the public marketing/catalogue website extracted from the Manus project.

## Deploy on Vercel
- Import this repository into Vercel.
- Build command: `npm run build`
- Output directory: `dist`
- Then add `nescoelevators.in` and `www.nescoelevators.in` under Domains.

## Important
The private Quotation Studio/database/admin functions are intentionally not included in this public static build. They remain in the original Manus project.

The current public media files continue to use the published Manus media URLs so the design/media is preserved without duplicating the media library. Keep the original Manus deployment published while using this version.
